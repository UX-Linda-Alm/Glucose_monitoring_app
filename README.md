This is a student project where I wanted to create a prototype for a "Glucose monitoring app" for relatives to a person with diabetes.
In my prototype the glucose data is automatically generated to make testing possible.

The app is a web based application and it can be tested by opening index.html in a web browser.
The code base is HTML, CSS, and JavaScript to make it simple and possible to understand even with just a little coding experience.


*** IMPORTANT *** 
This app is NOT a finished product and should NOT be used for real life glucose monitoring or medical desicions.
The glucose values in this app are automatically generated, fictive and NOT received from any live sensor.
